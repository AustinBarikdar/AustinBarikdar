### What I've built

**[LunaIDE](https://github.com/AustinBarikdar/LunaIDE)** · *TypeScript · React · Electron · MCP · LSP*<br>
A desktop IDE where teams of Claude Code and Codex agents work side by side. A planner agent splits a job into tasks and hands them to coder agents through a local MCP server I wrote (10 tools for delegation, messaging and shared memory). Every change gets explained line by line on the code itself. ~11K lines of TypeScript, with LSP support and built-in Git.

**[LuneTest](https://github.com/AustinBarikdar/LuneTest)** · *Luau · Lune · GitHub Actions · Roblox Open Cloud*<br>
An open-source testing framework for Roblox games, published on Wally. It runs ~6,000 unit tests in ~0.2s from one terminal command, without opening Roblox Studio. A hybrid runner sends only the tests that need the real engine to a background Studio session, and CI runs server tests on Roblox's own servers. [Website](https://austinbarikdar.github.io/LuneTest/)

**[Parrot](https://github.com/shinhajun/parrot)** · *Next.js · Supabase · WebRTC · Gemini · ElevenLabs*<br>
🏆 **Best Use of ElevenLabs** + **Runner-up, Diversity & Inclusion** at HopperHacks 2026.<br>
A real-time video-call translator that speaks each person's words in 15 languages in their own cloned voice, about 1.9s end to end.

**[Cobalt](https://github.com/shinhajun/Cobalt)** · *Electron · Node.js · JavaScript*<br>
🏆 **Best Use of AI/ML** at SBUHacks 2025.<br>
An AI desktop browser where an LLM agent navigates, clicks and types on live pages while you watch. I led the macOS port of the 45,000-line Electron codebase.

**More:** [Live Directory Tree](https://github.com/AustinBarikdar/Live-Directory-Tree-Plugin) (live sync from Roblox Studio to VS Code for AI context) · [CodeGuardian](https://github.com/AustinBarikdar/CodeGuardian) (GitHub App that reviews pull requests with an LLM)
